# Carrier Clear

Website for [Carrier Clear](https://github.com/TruckitTools/carrier-clear) — dedicated carrier compliance for freight brokers, shippers, and agents.

## Run locally

```bash
npm install
npm run dev
```

Then open the URL Vite prints. Build with `npm run build`.
